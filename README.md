# DemandIA — MVP

Este pacote é a primeira versão funcional da DemandIA: um assistente de IA para ajudar empresas a resolver demandas, tirar dúvidas e organizar tarefas.

## Instalação

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Copie `.env.example` para `.env`.
4. Preencha `OPENAI_API_KEY`.
5. No terminal, execute `npm install`.
6. Execute `npm run dev`.
7. Abra `http://localhost:3000`.

A chave da API fica somente no backend.
